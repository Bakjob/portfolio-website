# Decisions

Numrerade, permanenta beslut om portfolio website som utesluter ett
alternativ. Numrera aldrig om och ta aldrig bort en fil. Om ett beslut ändras,
lägg till en ny numrerad fil och peka den gamlas `Status`-rad på den.

## Mall

```markdown
# NNNN: Kort titel

**Status:** Gällande (eller: Ersatt av [0007](./0007-slug.md))

**Beslut:** En eller två meningar: vad som nu gäller.

**Varför:** De faktiska skälen. Nämn det konkreta fallet som ledde dit.

**Utesluter:** Vad detta stänger.

**Se även:** Relaterade beslut eller en längre text någon annanstans i vaulten.
```
