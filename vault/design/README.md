# Design

Allt om hur sajten ser ut och känns: färger, typsnitt, spacing, ikoner,
animationer och effekter (de "coola sakerna"), och mallarna för sidor som
upprepas. Beslut om stil som utesluter ett alternativ hör hemma i
`../decisions/`; här ligger själva specifikationen.

- **`page-families.md`**: sidtyper som följer samma mall (projektsidor),
  med route och sektionsordning per sida. Används av `content-page-family`.
